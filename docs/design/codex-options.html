Recommendation

Widget A with menu bar 2. Both keep one number per tool, so the layout doesn't change when Claude adds or drops a model limit.

  • When Codex isn't installed or signed in, its row is hidden and the widget shows Claude alone.
  • Bars use the tool color. They switch to amber at 80% and red at 95%, which replaces the severity field Codex doesn't send.
  • A Codex limit whose resets_at has passed shows 0% until Codex writes a new event.
  • The rings app icon and the MiniRings header mark go away. The "Quota Rings" name then no longer fits, so renaming is a separate decision.
